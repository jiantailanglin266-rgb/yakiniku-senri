## 未実装機能

優先度順。すべて**意図的に見送った**ものです。

### 高

| 項目                         | 理由と対応                                                                                                                                                                                                                   |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **取引所データの実測値**     | 手数料・スプレッド・最低取引額は検証できていないため、推測で書かず「公式サイトで要確認」を表示しています。公式サイトで確認のうえ `src/portal/data/exchanges.ts` を更新し、`checkedAt` と `DATASET_STATUS` を設定してください |
| **管理画面の認証・書き込み** | 認証なしで書き込み口を公開しないため、読み取り専用に留めています。`docs/portal/03-database.md` の手順で Supabase Auth → RLS → 監査ログ → 書き込み機能の順で実装してください                                                  |
| **ニュースの実データ取得**   | 実在メディアの記事を装ったサンプルは書けないため、レイアウト確認用の明示的なサンプルにしています。RSS/API 取得層を `src/portal/lib/` に追加し、同じ `NewsArticle` 型を返せば画面は変更不要です                               |

### 中

| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 生成モデル版チャットボット           | 現在は抽出型（捏造が構造的に起きない）。`retrieve()` の結果を文脈に渡す `/api/chat` を追加すれば切り替えられます。静的書き出しでは POST ルートを持てないためサーバー実行が前提です |
| ~~ニュース／画像・動画サイトマップ~~ | 実装済み。ただし静的書き出しでは「公開2日以内」の判定がビルド時刻で固定されるため、運用ではサーバー実行か定期ビルドが必要です                                                      |

| アフィリエイトのA/Bテスト            | `OutboundLink` に `variant` を足し、`affiliate_clicks.variant` に記録する設計まで済                                                                                                |

| 型                                    | 状態                             |
| ------------------------------------- | -------------------------------- |

| Article / NewsArticle                 | ✅                               |

> `tests/portal-lib.test.ts` で出力されないことを検証しています。

### 公開前に必ずやること

1. `npm audit` を実行し、High 以上を解消する
2. 管理画面（`/{locale}/admin`）に Basic 認証または Middleware でアクセス制限をかける
3. `AFF_*` を設定したら、PR表記と `rel="sponsored"` が出ることを実機で確認する
4. `src/portal/data/legal.ts` の `[[ 確定後に記入 ]]` をすべて埋める
5. 取引所データの数値を確認し、`checkedAt` と `DATASET_STATUS` を更新する
