# CRYPTO PORT の画像

ライセンス判定・掲載可否・クレジット表示の**規約そのもの**は
[`docs/media/`](../media/README.md) にあり、CRYPTO PORT だけの独自ルールはありません。
サイトごとに判定を持つと、片方だけ基準が緩くなる余地が生まれるためです。

このページでは、CRYPTO PORT 側の**つなぎ込み**だけを説明します。

## 1. 現状

**掲載中の Wikimedia 画像は 0 件です。**

実装した環境から Wikimedia のホストへ到達できず
（`commons.wikimedia.org` などが組織のegressポリシーで遮断されています）、
ライセンス・作者・出典を1件も検証できていません。
検証していない画像を「それらしく」登録することはしていません。

そのため現在、各枠には**サイト独自の装飾表現**（外部素材を使わない CSS/SVG）が出ます。
レイアウトは画像の有無で崩れません。

ネットワークの通る環境で次を実行すると、検証を通ったものだけが登録されます。

```bash
npm run media:sync -- --dry-run   # 取得して判定結果を表示（書き込まない）
npm run media:sync -- --write     # assets を更新
```

## 2. 掲載枠キー

`src/portal/lib/media.ts` の `portalPageKey()` で組み立てます。

| 種別     | キー                      | 枠          | 表示                 |
| -------- | ------------------------- | ----------- | -------------------- |
| ニュース | `cryptoport:news:<slug>`  | `card`      | 一覧カードの上部の帯 |
| 動画     | `cryptoport:video:<slug>` | `thumbnail` | サムネイル枠         |
| 銘柄詳細 | `cryptoport:coin:<slug>`  | `inline`    | 「概要」の直後の図版 |
| 学習記事 | `cryptoport:learn:<slug>` | `inline`    | 「定義」の直後の図版 |

`card` / `thumbnail` は `MediaSlot` を使い、画像が無ければ装飾表現に落ちます。
`inline` は `WikimediaFigure` を使い、画像が無ければ**何も表示しません**。
本文中に意味のない装飾を挟むと、読者に無関係な情報を見せることになるためです。

## 3. 装飾テーマの割り当て

画像が無い枠の見た目は、ニュースのカテゴリごとに変えています
（`newsFallbackTheme()`）。一覧が同じ絵柄で埋まらないようにするためで、
角度の種は slug から決めます（乱数だとサーバーとクライアントで表示がずれます）。

## 4. 出典表示

- **画像のすぐ近く**にクレジットを出します。記事末尾や一覧ページだけで済ませません
- 一覧は `/<言語>/image-credits`。フッターの「サイトについて」から常時たどれます
- 作者名・ファイル名・ライセンス正式名称・`Wikimedia Commons` は
  多言語ページでも訳さず、`translate="no"` を付けます。
  訳すとライセンスが求める「作者の表示」を満たさなくなります

## 5. YouTube のサムネイルについて

動画カードのサムネイル枠に、YouTube の `i.ytimg.com` 由来の画像は**出していません**。
サムネイルの権利者は各チャンネルであり、Wikimedia の判定基準では判断できないためです。
現在は装飾表現（再生アイコン＋長さ）を表示しています。

## 6. 構造化データとサイトマップ

`pageImagesJsonLd()` / `pageImageSitemapEntries()` は掲載可能な画像しか返しません。
確認の済んでいない画像が `ImageObject` や画像サイトマップへ漏れることはなく、
「構造化データは画面に表示している内容とだけ一致させる」という方針が保たれます。

## 7. 管理画面

`/<言語>/admin` の健全性チェックに、画像の項目が出ます。

| 状態                       | 重要度 |
| -------------------------- | ------ |
| 画像が0件（同期が未実行）  | 中     |
| 掲載可否の確認が未了       | 高     |
| 代替テキストが未設定       | 中     |
| 継承（ShareAlike）が必要   | 低     |
| 存在しない画像を指す掲載枠 | 中     |
