# CRYPTO PORT — 設計方針とページ一覧

> 仮称です。サイト名・ロゴ・ドメインはすべて環境変数で差し替えられます（`.env.example` 参照）。

---

## 1. サイト全体の設計方針

### コンセプト

**「未来の金融市場を可視化する、次世代 Web3.0 ターミナル」**

Bloomberg のような情報密度、CoinGecko のような数値の読みやすさ、Awwwards 掲載レベルの
視覚表現を1つの画面で成立させます。

### 設計上の優先順位

装飾と情報がぶつかったときは、**必ず情報を優先**します。具体的には次の順です。

1. **価格・変動率・比較表が読めること** — 最前面のレイヤーに、実線のカード上に置く
2. **どのデータがいつ取得されたか分かること** — 全画面に「取得日時」と更新間隔を表示
3. **表示が速いこと** — 3D ライブラリを入れず、CSS 3D / SVG / 2D canvas で表現
4. **装飾の豊かさ** — 背景・粒子・オーロラは低コントラストで背面に置く

### 事実性のルール（このプロジェクトの根幹）

| ルール                                   | 実装                                                                                           |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 未確認の数値を載せない                   | 手数料・スプレッド等は既定で「公式サイトで要確認」。`checkedAt` が空なら画面に「未検証」バッジ |
| モックであることを隠さない               | `MarketSnapshot.source === "mock"` のとき全画面にバッジ表示                                    |
| 実在しないレビューを構造化データにしない | `Review` / `AggregateRating` を**一切出力しない**（テストで担保）                              |
| 存在しない動画を宣言しない               | `youtubeId` が空なら `VideoObject` を出力しない                                                |
| 誤認を招く表現を使わない                 | 「必ず上がる」「元本保証」等は使用禁止。チャットボットもガードレールで拒否                     |
| 終了した特典を出さない                   | キャンペーンは条件を確認できたものだけ。既定は空                                               |

これらは `tests/portal-data.test.ts` / `tests/portal-lib.test.ts` で検証しています。

## 3. トップページのセクション構成

要件どおりの順序です。上ほど「今すぐ知りたい情報」、下ほど「じっくり読む情報」。

1. **ファーストビュー** — 3Dコイン、粒子ネットワーク、検索窓、3つのCTA、市場サマリー、Fear & Greed
2. **マーケットティッカー** — 13銘柄の価格・変動率が横に流れる（継ぎ目なし・hoverで停止）
3. **マーケット概要** — 時価総額・出来高・ドミナンス／上昇・下落・トレンド・新規上場
4. **最新ニュース** — カード6件（カテゴリ・ラベル・情報元・公開日時）
5. **急上昇ニュース** — 閲覧数・クリック・シェアを経過時間で割り引いたランキング
6. **注目の仮想通貨** — ロゴ・価格・変動率・スパークライン・時価総額
7. **国内取引所比較** — 上位3社カード → 比較表へ
8. **海外取引所比較** — 法規制の注意を先に読ませてから一覧
9. **ウォレット比較** — 4件（秘密鍵に関する注意を先出し）
10. **Web3.0ツール** — 14カテゴリのタグ + 6件
11. **YouTube動画** — 通常3件 + ショート
12. **仮想通貨診断** — 7種類のうち4件
13. **AIチャットボット** — 役割と禁止事項の説明
14. **学習コンテンツ** — 難易度ラベルつき6件
15. **最新キャンペーン** — 確認済みのみ（現在は空）
16. **メルマガ・SNS登録**
17. **FAQ**
18. **フッター** — リスク注記・アフィリエイト明示（全ページ共通）

## 4. ユーザー導線

```
                     ┌─────────────────────────────┐
  検索エンジン ──────▶│ 通貨詳細 / 学習記事 / ニュース │
  SNS ──────────────▶└───────────┬─────────────────┘
  YouTube 概要欄 ────▶ 動画LP ────┤
                                 │  「で、どこで買えばいい？」
                                 ▼
                     ┌───────────────────────┐
                     │ 取引所比較 / 取引所詳細 │◀── 診断結果
                     └───────────┬───────────┘
                                 │  rel="sponsored nofollow" + PR表記
                                 ▼
                          公式サイト（口座開設）
```

### 主要な3経路

1. **情報 → 比較 → 送客**
   通貨詳細の「購入できる取引所」→ 取引所詳細 → 口座開設CTA
2. **迷い → 診断 → 送客**
   ヘッダーの常設CTA → 診断（8問）→ 条件に合う取引所 + 理由 + 注意点
3. **YouTube → LP → 送客**
   動画の概要欄 → 動画LP（要約・目次・文字起こし）→ 関連取引所・ツール

### 迷子にしない仕掛け

- 全ページにパンくず（構造化データつき）
- ヘッダーの検索は表記ゆれに対応（`Bitcoin` / `ビットコイン` / `BTC`）
- AIチャットボットが、回答の最後に必ず関連ページを提示
- 学習記事に「次に読む」
