# デザインシステム

実装は `src/app/(portal)/portal.css`（Tailwind CSS v4 の `@theme`）。

---

## 配色

背景は黒〜ディープネイビーで固定し、彩度の高い色は**データを指し示す場所にだけ**使います。
全面をネオンにすると数値が読めなくなるため、発光は「面」ではなく「縁」と「点」に寄せています。

### 面（背景）

| トークン            | 値        | 用途         |
| ------------------- | --------- | ------------ |
| `--color-void`      | `#04050a` | body の地色  |
| `--color-abyss`     | `#070a16` | 沈んだ面     |
| `--color-navy`      | `#0b1024` | カードの下地 |
| `--color-navy-soft` | `#121935` | ガラスの下地 |
| `--color-slate`     | `#1b2444` | 区切り面     |

### アクセント

| トークン          | 値        | 用途                             |
| ----------------- | --------- | -------------------------------- |
| `--color-cyan`    | `#22d3ee` | 一次アクセント・フォーカスリング |
| `--color-blue`    | `#3b82f6` | グラデーション中間               |
| `--color-violet`  | `#8b5cf6` | 二次アクセント                   |
| `--color-magenta` | `#d946ef` | グラデーション終端               |
| `--color-emerald` | `#10d9a0` | 対応あり（○）                    |
| `--color-amber`   | `#fbbf24` | 注意・一部対応（△）              |

### 相場の方向

| トークン       | 値        | 併用する記号               |
| -------------- | --------- | -------------------------- |
| `--color-up`   | `#10d9a0` | ▲ + 「上昇」（読み上げ用） |
| `--color-down` | `#f43f5e` | ▼ + 「下落」               |
| `--color-flat` | `#94a3b8` | — + 「変化なし」           |

> **色だけで方向を示さない**のは固定要件です。色覚特性のある利用者に伝わらないためです。
> `PriceChange` コンポーネントが記号と `sr-only` テキストを必ず出します。

| `--color-ink-soft` | `#b6c0e0` | 補足             |
| `--color-ink-dim`  | `#7d88ab` | ラベル・メタ情報 |

## タイポグラフィ

| 役割    | フォント       | 用途                                 |
| ------- | -------------- | ------------------------------------ |
| Display | Space Grotesk  | 見出し・ロゴ                         |
| Body    | Inter          | 本文                                 |
| Mono    | JetBrains Mono | **すべての数値**、ティッカー、コード |

数値は `font-variant-numeric: tabular-nums`（`.tabular`）を必ず付けます。
桁が揃わないと比較表が読めなくなるためです。

## レイヤー構造

`body` 直下に固定配置し、ページ全体で1枚の連続した空間を作ります。
セクションごとに背景を持たせると継ぎ目が見えます。

| クラス       | z-index | 内容                                         |
| ------------ | ------- | -------------------------------------------- |
| `.bg-deep`   | -4      | メッシュグラデーション（放射 + 線形の合成）  |
| `.bg-aurora` | -3      | オーロラ。34秒周期でゆっくり移動             |
| `.bg-grid`   | -2      | サイバーグリッド。下方向へフェード（奥行き） |
| `.bg-noise`  | -1      | ノイズ。グラデーションのバンディングを潰す   |
| （中間）     | 0       | 粒子ネットワーク（canvas）、3Dコイン         |
| （前面）     | 1+      | 見出し・価格・CTA・比較表                    |

## コンポーネントの見た目

| クラス           | 用途                         | 注意                                                     |
| ---------------- | ---------------------------- | -------------------------------------------------------- |
| `.glass`         | 半透明カード                 | `backdrop-filter` は負荷が高いので面積の大きい要素だけに |
| `.glass-strong`  | ヘッダー・モーダル・sticky列 | 背面の文字が透けると読めなくなるため不透明寄り           |
| `.edge-glow`     | hover で縁が光る             | 常時発光はうるさく電池も食うので hover / focus のみ      |
| `.edge-flow`     | 光が流れるボーダー           | 注目させたい1〜2箇所だけ                                 |
| `.text-gradient` | 見出しのグラデーション       | 長文には使わない（読みにくい）                           |
| `.coin3d`        | CSS 3D のコイン回転          | Three.js 不使用                                          |
| `.marquee`       | ティッカーの横スクロール     | 2組並べて -50% で巻き戻す（継ぎ目防止）                  |
| `.chart-draw`    | チャートの描画アニメーション | `stroke-dashoffset`                                      |
| `.scroll-fade`   | 横スクロール領域の端フェード | 続きがあることを示す                                     |

## アニメーション

| 演出                                 | 実装                   | 備考                       |
| ------------------------------------ | ---------------------- | -------------------------- |
| スクロール連動フェード／スライドイン | Framer Motion `Reveal` | `once: true`               |
| 数字のカウントアップ                 | `CountUp`（rAF）       | 画面に入ったとき1回のみ    |
| マウス追従の立体傾斜                 | `TiltCard`（CSS 変数） | タッチ端末では何も起きない |
| 価格変動のフラッシュ                 | CSS keyframes          | 更新が届いた瞬間に差分だけ |
| 背景粒子 + ネットワーク線            | 2D canvas              | 画面外では rAF を停止      |
| 3Dコイン回転                         | CSS `preserve-3d`      | 追加バンドルゼロ           |
| ニュースティッカー                   | CSS `marquee`          | hover / focus で一時停止   |

### `prefers-reduced-motion`

- 装飾アニメーションは**完全停止**（`animation: none`）
- ティッカーは流れなくなる代わりに**横スクロール可能**になる
- カウントアップは最終値を即座に表示（状態を経由せず描画）
- チャートは `stroke-dashoffset: 0` で最初から完成形

| ブレークポイント | 幅     | 主な変化                                 |

### スマートフォンでの優先表示

価格 → 変動率 → CTA → 検索。ナビゲーションは折りたたみます。
比較表は**横スクロールだけに頼らず**、カード表示へ切り替えられます（`CompareTable`）。

## 右横書き（RTL）

アラビア語では `<html dir="rtl">` になります。
方向依存のスタイルはすべて**論理プロパティ**で書いてください。

- `ms-*` / `me-*`（`ml-*` / `mr-*` ではなく）
- `ps-*` / `pe-*`
- `start-*` / `end-*`
- `text-start` / `text-end`

矢印など反転させたい装飾には `.flip-rtl` を付けます。
