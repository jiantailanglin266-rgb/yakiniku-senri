# 画像の承認前チェックリスト

`verificationStatus` を `approved` にする前に、**すべて**確認してください。
1つでも「いいえ」があれば承認しません。

## A. 出所

- [ ] その画像は **Wikimedia Commons に登録されたファイル**か
      （Wikipedia の記事に表示されているだけの画像は対象外。各言語版へのローカルアップロードは
      フェアユース等の非自由ファイルを含みます）
- [ ] Commons のファイルページ URL が取得できているか
- [ ] ファイルページを実際に開いて、テンプレートと注意書きを読んだか

## B. ライセンス

- [ ] ライセンスの正式名称が確定しているか（「CC BY」だけで版が不明なら**不可**）
- [ ] 商用利用が許可されているか（NC は不可）
- [ ] 改変が許可されているか（ND は不可。当サイトはトリミングとオーバーレイを行うため）
- [ ] 継承（ShareAlike）の要否を把握しているか
- [ ] 作者表示の要否を把握しているか
- [ ] 複数ライセンスが併記されている場合、どれを採用するか決めたか

## C. クレジット

- [ ] 作者名が取得できているか（不明なら、作者表示が必要なライセンスでは**不可**）
- [ ] 作者名・ライセンス正式名称・"Wikimedia Commons" を**原文のまま**出すようになっているか
- [ ] クレジットが画像のすぐ近くに出るか（記事末尾の一覧だけでは足りません）
- [ ] クレジットが読める大きさか（0.68rem 以上・背景とのコントラストを確保）
- [ ] 加工した場合、その旨を明示しているか

## D. ライセンス以外の権利

ライセンスは著作権だけの話です。以下は**別に**確認します。

- [ ] 人物が写っていないか（写っている場合、肖像権・パブリシティ権の確認）
- [ ] 子どもが写っていないか
- [ ] 企業ロゴ・商標が写っていないか
- [ ] 商品パッケージ・カード券面が写っていないか
- [ ] 美術作品・彫刻・壁画が写っていないか
- [ ] 建築物が主題になっていないか
      （フランス・イタリア・ベルギー・ギリシャ・アイスランド・ウクライナなどは
      「パノラマの自由」が制限されます）
- [ ] イベント・試合の写真ではないか（主催者の規約が及ぶことがあります）

## E. 掲載文脈

- [ ] その画像は、そのページの内容と**実際に関係している**か
      （装飾目的で関連の薄い画像を貼らない）
- [ ] 読者に誤解を与える組み合わせになっていないか
      （例: 実在企業の写真を、架空カードの説明に添える）
- [ ] 当サイトが撮影者・作者であるかのように読めないか
- [ ] Wikimedia / Wikipedia が当サイトを推奨しているように読めないか
- [ ] 画像の加工が、事実を誤認させる方向になっていないか
      （合成・切り取りによる印象操作・色調で意味を変える等）

## F. 記録

- [ ] `verifiedAt` と確認者を記録したか
- [ ] `verificationNotes` に判断の根拠を残したか
- [ ] 却下した候補は `image_rejections` に理由つきで残したか

---

## 承認できないときの扱い

| 状況                       | 状態                        | 画面での扱い         |
| -------------------------- | --------------------------- | -------------------- |
| ライセンスが読めない       | `license_unknown`           | 表示しない（装飾へ） |
| 作者不明（作者表示が必要） | `needs_review`              | 表示しない           |
| 被写体の権利が未確認       | `rights_risk`               | 表示しない           |
| 非商用・改変禁止           | `rejected`                  | 表示しない           |
| 一時的に取り下げたい       | `usageStatus = "suspended"` | 表示しない           |

**「たぶん大丈夫」で承認しないでください。** 保留は無料ですが、権利侵害は取り返しがつきません。
