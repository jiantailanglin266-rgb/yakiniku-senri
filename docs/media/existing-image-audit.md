## 2. 分かったこと

### 2-1. 出自の記録が存在しない

**90件すべてについて、撮影者・提供元・撮影日・利用条件の記録がありません。**
リポジトリ内に、画像の権利情報を保持する仕組み自体がありませんでした
（`src/media/` はそれを作るためのものです）。

- 千里の店舗・料理写真（約25件）は、店舗自身の素材と推測されますが、
  **推測なので記録には書きません。** 撮影者の確認が必要です。
- 国旗（42件）の出所を追跡しました（下記 2-5）。**記録を作成済みです。**
- `cardport/` の6件はこのリポジトリの `scripts/generate-cardport-assets.mjs` が
  生成したもので、外部素材を含みません。

### 2-2. Wikimedia の画像は 1 件も使っていない

既存の90件に、Wikimedia Commons 由来のファイルはありません。
したがって、**今回の対応で「既存のWikimedia画像を差し替える」作業は発生しません。**

### 2-3. クレジット表示の仕組みが無かった

画像に作者・出典・ライセンスを添えるコンポーネントが存在しませんでした。
`ImageAttribution` / `ImageSourceDetails` / `/image-credits` で新設しています。

### 2-5. 国旗素材（42件）は flag-icons 由来で、著作権表示が欠けていた

追跡結果：

1. リポジトリの履歴（コミット `27f0552`「言語プルダウンに国旗を追加し、固定要件として記録」）に
   「flag-icons（MIT）のSVGを 48x36 の WebP へ変換」と記録がありました。
2. 配布元（<https://github.com/lipis/flag-icons>）の `LICENSE` 原文を取得し、
   著作権者名（Panayiotis Lipiridis）と本文を照合しました。

**MIT は「著作権表示と許諾表示を複製物または重要な部分に含めること」が条件です。**
国旗は5サイトすべてのヘッダーに出ているのに、著作権表示はドキュメント内の
1行（`docs/seo/08-multilingual.md`）だけで、**サイト上には一切ありませんでした**。
条件を満たしていない状態です。

対応：

- 全文を `public/licenses/flag-icons-LICENSE.txt` に掲載
- 5サイトすべての言語切り替えプルダウンからリンク（素材を表示している画面から辿れる位置）
- `src/media/data/site-assets.ts` に作者・出典・ライセンス・改変内容を記録
- `tests/media-site-assets.test.ts` で、導線が消えたら落ちるようにした

> 「国旗のデザイン自体は著作権の対象外」であることと、
> 「その SVG を作った人の権利」は別です。前者を理由に後者を省略できません。

### 2-4. YouTube サムネイルの外部参照

`i.ytimg.com` のURLが構造化データとフィードに含まれています
（`src/cardport/lib/structured-data.ts` / `feeds.ts` / `src/portal/lib/structured-data.ts` /
`src/lib/ai-port/youtube.ts`）。

- 構造化データ・RSS の `<image>` は、YouTube が定める埋め込み・参照の範囲です。
- ただし**ページ本文でのホットリンクは行わない**方針にしました。
  CARD PORT の動画一覧は `MediaSlot`（装飾）に置き換え済みです。

## 4. 未確認のものを「確認済み」に見せない

`/card-port/<言語>/image-credits` は、
**ライセンスを確認できた画像だけ**を並べます。

現在は0件なので、一覧の代わりに
「まだ確認できた画像はない」旨をそのまま表示しています。
それらしい一覧を作って「確認済み」に見せることはしません。

## 5. Wikimedia 以外の素材の台帳

`src/media/data/site-assets.ts` に、自作・外部素材・出所未確認の3種類で記録しています。
AI PORT の `/ai-port/image-credits` に一覧を表示しています。

| 素材                        | 点数 | 区分       | ライセンス |
| --------------------------- | ---: | ---------- | ---------- |
| 言語切り替えの国旗          |   42 | 外部素材   | MIT        |
| CARD PORT の OGP・アイコン  |    6 | 自作       | —          |
| SPORTS PORT・ポータルの OGP |    2 | 自作       | —          |
| AI PORT のロゴ・OGP         |    2 | 自作       | —          |
| 焼肉 千里 の写真・図版      |   38 | 出所未確認 | 未確認     |

**「出所未確認」を「自作」と書きません。** 推測を記録に書くと、記録そのものが信用できなくなります。
テストで、未確認の素材に作者名や確認日が入っていないことを確認しています。
