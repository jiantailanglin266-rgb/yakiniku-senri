# 画像を追加する手順

## 0. 最初に読むこと

**「Wikipedia に載っているから自由に使える」は誤りです。**

- Wikipedia の記事に表示されている画像には、各言語版へローカルアップロードされた
  **フェアユース等の非自由ファイル**が含まれます。日本のサイトで再利用できません。
- 対象は **Wikimedia Commons に登録されたファイル**だけです。
- Commons のファイルでも、ライセンス・作者・出典・利用条件を**1件ずつ**確認します。

## 1. 手順

### ステップ1 — 何の画像が要るのかを決める

`src/media/data/requests.json` に、掲載枠と検索語を書きます。

```json
{
  "pageKey": "cardport:guide:points-basics",
  "slot": "inline",
  "query": "contactless payment terminal",
  "wikidataEntityId": null,
  "limit": 5
}
```

**装飾のために枠を作らないでください。**
「この記事にはこの画像が必要」と説明できないなら、装飾（`FallbackVisual`）のままにします。

### ステップ2 — 取得する

```bash
node scripts/wikimedia-sync.mjs --dry-run   # まず確認だけ
node scripts/wikimedia-sync.mjs --write     # 問題なければ書き込み
```

スクリプトは `approved` を付けません。すべて保留状態で止まります。

### ステップ3 — Commons のファイルページを開く

**API の結果だけで判断しないでください。** 必ず人がページを開きます。

- ライセンステンプレート（`{{cc-by-sa-4.0}}` など）
- 作者・出典の記述
- Personality rights warning（肖像権の注意書き）
- Trademarked（商標の注意書き）
- 撮影国と「パノラマの自由」

### ステップ4 — チェックリストを通す

[license-checklist.md](license-checklist.md) を最初から最後まで通します。
1つでも「いいえ」があれば承認しません。

### ステップ5 — 代替テキストを書く

`AssetLocalization` に、その言語での `altText` を必ず用意します。
**alt が無い画像は表示されません**（`resolveImage()` が `null` を返します）。

翻訳するのは次の3つだけです。

| 項目                                  | 翻訳       |
| ------------------------------------- | ---------- |
| `altText` / `caption` / `description` | する       |
| 作者名                                | **しない** |
| 作品名・ファイル名                    | **しない** |
| ライセンス正式名称                    | **しない** |
| "Wikimedia Commons"                   | **しない** |
| Commons の URL                        | **しない** |

作者名を訳すと、ライセンスが要求する「作者の表示」を満たさなくなります。

### ステップ6 — 承認する

管理画面（`/card-port/<言語>/admin`）で状態と根拠を確認し、承認します。
承認と同時に `verifiedAt` と履歴（`image_verification_logs`）を残します。

## 2. やってはいけないこと

| 行為                                     | 理由                                       |
| ---------------------------------------- | ------------------------------------------ |
| Google 画像検索の結果をコピーする        | 出所もライセンスも分かりません             |
| Wikipedia のスクリーンショットを貼る     | 記事のレイアウト自体にも権利が及びます     |
| ライセンス確認を飛ばして掲載する         | 「表示されている」ことは許諾ではありません |
| 作者・出典・ライセンスの記録を消す       | 後から検証できなくなります                 |
| 利用条件が不明な画像を掲載する           | 不明は「自由」ではありません               |
| フェアユース前提の画像を商用利用する     | 日本にフェアユース規定はありません         |
| クレジットを小さく・薄く出す             | 表示義務を満たしません                     |
| クレジットをモーダルの中だけに隠す       | 画像の近くに出す必要があります             |
| 意味が変わる加工をする                   | 誤認を招きます                             |
| 当サイトが作者であるかのように見せる     | 事実と異なります                           |
| Wikimedia の推奨を受けているように見せる | 事実と異なります                           |

## 3. 画像が用意できないとき

**それでかまいません。**

`MediaSlot` は画像が無ければ `FallbackVisual`（CSS と SVG だけの装飾）に落ちます。
外部素材を使わないので、権利上の懸念がありません。

関連の薄い画像を貼るより、装飾のままにしてください。
`lib/scoring.ts` の関連度しきい値（45）は、そのための仕組みです。

## 4. 加工について

トリミング（`object-fit` / `object-position`）とオーバーレイは**改変**に当たります。

- 改変が許可されていないライセンス（CC BY-ND）の画像は、そもそも掲載対象外です。
- 加工した場合は `isModified` を立て、クレジットに「（当サイトで加工）」が出ます。
- 継承（ShareAlike）が必要な画像を加工した場合、**生成物にも同じライセンス**が要ります。
  OGP 画像を作るときは `requiresShareAlikeOnDerivative()` で判定してください。
