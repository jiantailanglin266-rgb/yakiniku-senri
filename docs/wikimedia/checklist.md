# 画像を1枚公開するまでの確認手順

自動判定が通ったものでも、人間が見るべき点は残ります。
`src/wikimedia/data/reviews.json` に `approved` を書く前に、以下を確認してください。

## 1. ライセンスの確認（機械が判定済み。目視で裏を取る）

- [ ] Commons のファイルページを**実際に開いた**（`commonsPageUrl`）
- [ ] ライセンステンプレートが1つだけか（複数ある場合、どれが適用されるか）
- [ ] 「この画像の被写体は別の著作物」という注記が無いか
      （例：彫刻を撮った写真は、写真と彫刻の2つの権利がある）
- [ ] 削除依頼・ライセンス争いのテンプレートが貼られていないか
- [ ] アップロード者と作者が違う場合、作者の許諾が示されているか

**「Wikipedia に載っているから自由に使える」は成立しません。**
Wikipedia には、フェアユースを根拠に掲載された画像が含まれます。
それらは Commons には無く、商用利用もできません。

## 2. クレジットの確認

- [ ] 作者名が原文のまま保存されているか（翻訳・省略しない）
- [ ] 作者ページへのリンクが生きているか
- [ ] ライセンスの正式名称とURLが入っているか
- [ ] Commons が推奨クレジット文を示していれば、それを使っているか
- [ ] 画面上でクレジットが読める大きさか（10px 未満にしない）

## 3. 追加権利の確認（ライセンスでは解決しない）

- [ ] **人物**が写っていないか
      → 存命人物は肖像権・パブリシティ権があります。
      報道目的でない使い方（トップページの装飾など）は避けてください。
- [ ] **子ども**が写っていないか → 使用しない
- [ ] **商標・ロゴ・ユニフォーム**が写り込んでいないか
      → クラブのエンブレム、スポンサーロゴ、大会ロゴは商標です。
      「オリンピック」関連の標章は特に規制が強い（商標法・オリンピック憲章）。
- [ ] **建築著作物**が主題になっていないか
      → 日本の著作権法46条は建築物の撮影を広く認めますが、
      フランス・イタリアなど「パノラマの自由」が無い国があります。
      撮影国を確認してください。
- [ ] **美術作品**（彫刻・壁画・グラフィティ）が主題になっていないか
- [ ] 撮影場所が**私有地・イベント会場**でないか（撮影条件が付くことがある）

該当したら `reviews.json` の `clearedRisks` には入れず、保留のままにします。
確認して問題ないと判断した場合のみ、その項目を `clearedRisks` に書きます
（何を確認したかを `note` に残してください）。

## 4. 使い方の確認

- [ ] ページの内容と関係のある画像か（装飾目的で無関係な写真を置かない）
- [ ] 画像の内容を誤認させる加工をしていないか
      （合成・切り抜きで文脈を変える、色を変えて別物に見せる、など）
- [ ] 文字を重ねる場合、被写体の顔や主題が隠れていないか
- [ ] CC BY-SA の場合、**改変したなら**同じライセンスで公開する必要がある
      → オーバーレイやトリミングは改変にあたりうるため、
      `isModified` を立てて加工内容を記録してください
- [ ] Wikimedia / Wikipedia が当サイトを公認していると誤解される表示になっていないか

## 5. 公開後

- [ ] `/image-credits` に出ているか
- [ ] 管理画面（`/admin`）の件数が想定どおりか
- [ ] 半年に1度、ライセンスが変更・削除されていないか再確認する
      （Commons では削除依頼が通ることがあります）

## 削除依頼が来たときの手順

1. 該当画像の `reviews.json` を `rejected` に変更してデプロイ（表示が即座に止まります）
2. `src/wikimedia/data/assets.generated.json` から該当レコードを削除
3. 依頼者へ対応内容を返信
4. 同じ画像を再取得しないよう、`rejections` に理由を記録

表示を止めるのに再取得は不要です。`reviews.json` の1行で止まります。
