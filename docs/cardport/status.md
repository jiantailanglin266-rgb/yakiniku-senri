# CARD PORT — 実装状況

作成日: 2026-08-04

---

## 実装済み機能

### 基盤

- 既存サイト（焼肉 千里）と完全分離した複数ルートレイアウト構成
- 14言語のルーティング（`/<locale>/...`、未定義コードは 404）
- サイト名・ロゴ・ドメイン・カラー・運営会社の環境変数化
- モック／本番データの切り替え口（`NEXT_PUBLIC_DATA_SOURCE`）
- 静的エクスポート対応（APIキー・サーバー無しで全機能が動作）

### デザインシステム

- ダークネイビー基調のカラートークン（環境変数から差し替え可）
- 背景3層（オーロラ／サイバーグリッド／ノイズ）
- ガラス表現・光るボーダー・文字グラデーション
- CSS 3D の券面（ISO/IEC 7810 ID-1 比率、コンテナクエリで文字が追随）
- 光の粒子と決済ネットワーク（Canvas 2D ＋ SVG、画面外で停止）
- マウス追従の傾き、浮遊、券面を流れる光、ティッカー、出現アニメーション、カウントアップ
- `prefers-reduced-motion` で全モーション無効化
- 印刷スタイル（比較表を紙で持ち出せる）

### ページ（22種類・全14言語）

トップ（21セクション）／カード検索／カテゴリ一覧（20）／カード詳細（20枚）／比較／
ランキング総覧／カテゴリ別ランキング（17）／診断一覧／診断（9種）／シミュレーター一覧／
シミュレーター（10種）／キャンペーン／法人カード／キャッシュレス決済／Web3.0 一覧／
Web3.0 詳細（6）／金融ツール／ニュース一覧／ニュース詳細（12）／動画一覧／動画詳細（6）／
ガイド一覧／ガイド詳細（6）／目的別特集一覧／特集詳細（19）／FAQ／固定ページ（13）／
管理画面／HTMLサイトマップ／404

本番ビルドで **2,225 ページ**を生成（約20秒）。

### 機能

- カード検索（全文検索・年会費・還元率・ブランド・ランク・申込み対象・目的・機能・発行スピード・並び替え）
- 条件のURL相互変換（絞り込んだ状態を共有できる）
- 比較（最大4枚、表／カード型の切り替え、1列目固定、localStorage 保持）
- 診断9種（決定的スコアリング、結果をURLで共有、根拠の表示）
- シミュレーター10種（前提条件と計算式を常時表示）
- AIコンシェルジュ（掲載データを検索して根拠つきで回答、機微情報の入力を遮断）
- キャンペーン期限の自動判定と表示切り替え
- アフィリエイトリンクの一元管理（`rel` 付与・計測・地域別・期限切れフォールバック）
- 同一発表のニュース統合（`storyKey`）
- 管理ダッシュボード（掲載件数・リンク状態・期限・情報鮮度）

### SEO

- title / description / canonical / hreflang / OGP / X Card
- 構造化データ 10種（実データのない `AggregateRating` と `Review` は意図的に非出力）
- サイトマップ（全ページ・言語相互参照）／ニュース／動画／RSS
- パンくず（表示と構造化データが同一データ）

### 法務・信頼性

- 執筆者・監修者・公開日・更新日・情報確認日の表示
- 広告開示（フッター全ページ ＋ PRラベル）
- ランキング評価基準の全文公開と、順位算出コードの広告からの分離
- 固定ページ13本
- 禁止表現の自動検出テスト

### 検証

- 型チェック・ESLint・Prettier・本番ビルドがすべて通過
- テスト 127件（データ整合性・ロジック・多言語・法務表現）

## 既知の問題・設計上の割り切り

| 内容                                              | 詳細                                                                                                                                                                                 |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 静的エクスポート時は詳細ページが `ja` / `en` のみ | ビルド時間の都合。`CARDPORT_CONTENT_LOCALES` で変更可。hreflang とサイトマップも同じ範囲に自動で揃います                                                                             |
| `<html lang>` の初期値が `ja` 固定                | ルートレイアウトが全言語共通のため。ハイドレーション後に `LocaleHtmlAttributes` が補正します。canonical と hreflang はサーバー側で正しく出力しているためクロールへの影響はありません |
| Three.js / React Three Fiber 未使用               | 表現に対して過剰で、初期バンドルが数百KB増えるため。`components/visual/` を差し替えれば移行可能                                                                                      |
| Framer Motion 未使用（CARD PORT 側）              | 出現アニメーションのために全ページへライブラリを配るコストを避けました。既存サイトでは引き続き使用しています                                                                         |
| フッターの年表示がビルド時固定                    | 静的生成のため。年をまたぐ場合は再ビルドが必要                                                                                                                                       |
| ラウンジ1回 = 1,100円の換算                       | 有料ラウンジの一般的な料金水準を仮置きした数値です。画面に前提として明記しています                                                                                                   |
