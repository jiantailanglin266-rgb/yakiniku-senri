## 1. SEO チェックリスト

### 基本

|     | 項目                                                                    | 実装                                               |
| --- | ----------------------------------------------------------------------- | -------------------------------------------------- |
| ✅  | 全ページに固有の `title`                                                | `lib/seo.ts` の `cardportMetadata()`               |
| ✅  | 全ページに固有の `description`                                          | 同上                                               |
| ✅  | `canonical`                                                             | 同上（言語つき絶対URL）                            |
| ✅  | `hreflang`（自己参照 ＋ `x-default`）                                   | `alternateLanguages()`。**生成した言語だけ**を宣言 |
| ✅  | OGP（`og:type` / `url` / `title` / `description` / `image` / `locale`） | 同上                                               |
| ✅  | X Card（`summary_large_image`）                                         | 同上                                               |
| ✅  | パンくず（表示＋構造化データ）                                          | `layout/Breadcrumbs`                               |
| ✅  | 内部リンク（関連カード・関連記事・関連比較）                            | 各詳細ページ                                       |
| ✅  | `robots.txt`                                                            | `src/app/robots.ts`                                |
| ✅  | サイトマップ（全ページ・言語相互参照つき）                              | `/cardport-sitemap.xml`                            |
| ✅  | ニュースサイトマップ（直近2日）                                         | `/cardport-news-sitemap.xml`                       |
| ✅  | 動画サイトマップ                                                        | `/cardport-video-sitemap.xml`                      |
| ✅  | RSS                                                                     | `/cardport-rss.xml`                                |
| ✅  | HTML サイトマップ                                                       | `/<locale>/sitemap`                                |
| ✅  | 管理画面を `noindex`                                                    | `/<locale>/admin`                                  |
| ⬜  | 画像サイトマップ                                                        | 実画像を入れてから作成                             |
| ⬜  | ページネーション（`rel=next/prev` 相当）                                | 現在は「もっと見る」方式。掲載数が増えたら分割     |

### 構造化データ

|     | 型                          | 出力箇所                             |
| --- | --------------------------- | ------------------------------------ |
| ✅  | `Organization`              | 全ページ（レイアウト）               |
| ✅  | `WebSite` ＋ `SearchAction` | 同上                                 |
| ✅  | `BreadcrumbList`            | パンくずのあるページ                 |
| ✅  | `FinancialProduct`          | カード詳細                           |
| ✅  | `ItemList`                  | 一覧・ランキング・特集               |
| ✅  | `NewsArticle`               | ニュース詳細                         |
| ✅  | `Article` / `HowTo`         | ガイド                               |
| ✅  | `VideoObject`               | 動画詳細                             |
| ✅  | `FAQPage`                   | FAQ・カード詳細・法人・Web3          |
| ✅  | `SoftwareApplication`       | 診断・シミュレーター                 |
| ❌  | `AggregateRating`           | **出力しない**（実データがないため） |
| ❌  | `Review`                    | **出力しない**（同上）               |

> 構造化データは、**画面に表示している内容とだけ**一致させてください。
> 表示していない値をマークアップに含めるのはポリシー違反です。

## 2. セキュリティ チェックリスト

### 機微情報

|     | 項目                                           | 実装                                   |
| --- | ---------------------------------------------- | -------------------------------------- |
| ✅  | カード番号を保存しない                         | 入力欄自体を作っていません             |
| ✅  | セキュリティコードを保存しない                 | 同上                                   |
| ✅  | 暗証番号を求めない                             | 同上                                   |
| ✅  | 本人確認書類を保存しない                       | 同上                                   |
| ✅  | チャットへの機微情報入力を検出して遮断         | `rag.ts` の `containsSensitiveInput()` |
| ✅  | チャット冒頭に警告を常時表示                   | `chat/Concierge`                       |
| ✅  | 診断・シミュレーターで過剰な個人情報を集めない | 氏名・住所・年収の具体額は尋ねません   |
| ✅  | 診断・比較の入力をサーバーへ送らない           | localStorage とメモリのみ              |

### 実装

|     | 項目                                             | 実装                                                                      |
| --- | ------------------------------------------------ | ------------------------------------------------------------------------- |
| ✅  | APIキーをクライアントへ露出しない                | `.env.example` に `NEXT_PUBLIC_` の使い分けを明記                         |
| ✅  | 環境変数の一元管理                               | `config/site.ts`                                                          |
| ✅  | XSS 対策                                         | React の自動エスケープ。`dangerouslySetInnerHTML` は自前生成のJSON-LDのみ |
| ✅  | 外部リンクに `noopener noreferrer`               | `affiliate.ts` / 各外部リンク                                             |
| ✅  | 外部リンクに `nofollow`（広告は `sponsored` も） | 同上                                                                      |
| ✅  | localStorage の読み取りを例外安全に              | `hooks/useCompare.ts`                                                     |
| ⬜  | CSRF 対策                                        | 書き込みAPIを追加する際に SameSite Cookie ＋ トークン                     |
| ⬜  | SQLインジェクション対策                          | Supabase クライアント経由（文字列連結でクエリを組まない）                 |
| ⬜  | 入力値検証（Zod）                                | 書き込みAPIを追加する際に                                                 |
| ⬜  | レート制限                                       | `/api/chat` `/api/track/click` に導入                                     |
| ⬜  | Bot 対策                                         | 購読フォームに Turnstile 等                                               |
| ⬜  | CSP ヘッダ                                       | `next.config.ts` の `headers()` で設定（YouTube 埋め込みを許可）          |
| ⬜  | 依存パッケージの脆弱性確認                       | `npm audit` を CI に追加                                                  |

### 管理画面

|     | 項目                                       |
| --- | ------------------------------------------ |

### 必須表示

| --- | -------------------------------- | ---------------------------------------------- |
| ✅  | 執筆者                           | カード詳細・記事・ガイド                       |
| ✅  | 監修者                           | 同上                                           |
| ✅  | 公開日・更新日                   | 同上                                           |
| ✅  | **情報確認日**                   | カード詳細・カード一覧・チャット回答           |
| ✅  | 参照元                           | 記事                                           |
| ✅  | 公式情報へのリンク               | 全カード・全サービス                           |
| ✅  | 広告を含む旨                     | フッター（全ページ）＋ PRラベル                |
| ✅  | ランキング評価基準               | `/policies/ranking-criteria` からリンク        |

| ✅  | 日本国内在住者向け商品である旨   | 日本語以外の言語で表示                         |
| ✅  | 暗号資産のリスク                 | Web3 ページ・暗号資産カード                    |

### 固定ページ（13本すべて作成済み）

運営者情報 / 編集方針 / ランキング評価基準 / 広告掲載ポリシー / アフィリエイトポリシー /
金融情報掲載方針 / 免責事項 / プライバシーポリシー / 利用規約 / Cookieポリシー /
著作権ポリシー / 情報修正依頼 / お問い合わせ

> ⚠ 運営会社情報が未設定の場合、画面に「未設定」と表示されます。
> 公開前に `NEXT_PUBLIC_CARDPORT_COMPANY` ほかを設定してください。

### 使用しない表現（テストで自動検出）

`tests/cardport-data.test.ts` が以下の混入を検出します。

- 必ず審査に通る
- 誰でも発行できる
- 絶対に得
- 確実に儲かる
- 無条件でもらえる
- 審査なしで作れる
- 100%発行
