# CARD PORT — ランキング評価基準（算定方法）

順位は編集部が手で並べるのではなく、**公開している評価軸と重みから機械的に計算**しています。
この文書はその算定方法の全文です。実装は `src/cardport/lib/scoring.ts` にあります。

---

## 1. 前提

- 掲載順位・評価点に、**アフィリエイト報酬額は一切影響しません**
- 算定コード（`scoring.ts`）は、アフィリエイト管理コード（`affiliate.ts`）を import しません。
  依存関係のレベルで、報酬額が順位に入り込めない構造にしています
- 同点の場合の並びまで決めているため、同じデータからは**毎回同じ順位**が出ます

---

## 2. 評価軸（6軸・各0〜5点）

| 軸               | 見ているもの                                                                         |
| ---------------- | ------------------------------------------------------------------------------------ |
| 還元率           | 基本還元率と、条件付きで到達できる最大還元率の両方。到達条件が厳しいほど加点を抑える |
| 年会費の負担     | 年会費の金額と、無料条件の達成しやすさ。無条件無料が最高点                           |
| 特典・優待       | ラウンジ・優待・付帯サービスの範囲。使う機会が限られる特典は加点を抑える             |
| 保険・補償       | 補償額と、自動付帯か利用付帯か                                                       |
| 使いやすさ       | 発行スピード、対応する決済手段、アプリの機能                                         |
| 発行会社の信頼性 | 事業基盤と情報開示の明確さ                                                           |

---

## 3. カテゴリ別の重み

同じカードでも、探している目的によって「良さ」は変わります。
そのためカテゴリごとに重みを変え、**その重みをランキングページに表示**しています
（`/card-port/ja/rankings/<category>`）。

正規化前の値（`scoring.ts` の `categoryWeights`）:

| カテゴリ           | 還元率  | 年会費  | 特典    | 保険    | 使いやすさ | 信頼性  |
| ------------------ | ------- | ------- | ------- | ------- | ---------- | ------- |
| 総合               | 3.0     | 2.5     | 2.0     | 1.5     | 2.0        | 2.0     |
| 年会費無料         | 3.0     | **4.0** | 1.0     | 0.5     | 2.0        | 1.5     |
| ポイント還元率     | **5.0** | 2.0     | 1.0     | 0.5     | 1.5        | 1.5     |
| マイル             | 3.0     | 1.5     | 3.0     | 2.0     | 1.5        | 1.5     |
| 旅行               | 1.5     | 1.5     | 3.0     | **4.0** | 1.5        | 1.5     |
| ゴールド           | 2.0     | 2.0     | 3.0     | 3.0     | 1.5        | 1.5     |
| プラチナ           | 1.5     | 0.5     | **4.0** | 3.0     | 1.0        | 2.0     |
| ブラック           | 1.0     | 0.2     | **4.5** | 3.0     | 1.0        | 2.5     |
| 法人               | 2.0     | 2.5     | 2.5     | 1.0     | **3.5**    | 2.0     |
| 個人事業主         | 2.0     | **3.5** | 1.5     | 0.5     | 3.0        | 2.0     |
| 学生               | 3.0     | **4.0** | 1.0     | 0.5     | 2.0        | 1.5     |
| 初めての1枚        | 2.5     | **4.0** | 1.0     | 0.5     | 3.0        | 2.0     |
| 海外利用           | 2.5     | 1.0     | 2.0     | **3.0** | 2.0        | 1.5     |
| ネットショッピング | **4.0** | 2.0     | 1.0     | 0.5     | 3.0        | 1.5     |
| コンビニ           | **4.5** | 3.0     | 0.5     | 0.2     | 2.0        | 1.0     |
| ガソリン           | **4.0** | 3.0     | 1.0     | 0.5     | 2.0        | 1.0     |
| サブスク           | **4.0** | 2.5     | 1.0     | 0.3     | 3.0        | 1.0     |

計算時に合計が 1 になるよう正規化します。

```
総合スコア = Σ（軸のスコア × 正規化した重み）     … 0〜5、小数第2位で丸め
```

---

## 4. 同点の扱い

1. 総合スコアが高い順
2. 同点なら **年会費が安い順**
3. それも同じなら **スラッグの辞書順**

3段階まで決めているのは、データを更新していないのに順位が入れ替わる状態を避けるためです。

---

## 5. 掲載しないもの

| 項目                              | 理由                                                                     |
| --------------------------------- | ------------------------------------------------------------------------ |
| `AggregateRating`（評価点の集計） | 当サイトのスコアは編集部の評価であり、利用者レビューの集計ではありません |
| `Review`（口コミ）                | 検証済みの実データがありません                                           |
| 受賞歴・メディア掲載実績          | 実績がありません                                                         |

いずれも、実データが揃うまでは画面にも構造化データにも出しません。
実データが揃った場合は `card_reviews` テーブルの `is_verified` が真のレコードのみを対象とし、
**画面に表示している内容とだけ一致させて**出力してください。

---

## 6. 更新のしかた

1. `src/cardport/data/cards.ts` の `scores`（6軸）を更新する
2. 重みを変えたい場合は `src/cardport/lib/scoring.ts` の `categoryWeights` を編集する
3. `npm run test` でスコア範囲と順位の再現性を検証する
4. ランキングページの重み表示は自動で追随します

順位を手で並べ替えたくなったときは、**まず評価軸か重みを見直してください**。
順位だけを直すと、公開している基準と実際の順位が食い違います。
