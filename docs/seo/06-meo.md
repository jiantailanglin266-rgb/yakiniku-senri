# MEO｜Googleビジネスプロフィール最適化

**前提**：焼肉店の新規来店において、**Googleマップからの流入がWeb検索を上回るのが一般的**です。
サイト改修よりGBP整備のほうが費用対効果が高いため、**最優先で着手してください。**

## 3. NAP統一（最重要）

**NAP（Name / Address / Phone）が1文字でも違うと、Googleは別店舗と認識します。**

```
名称：焼肉 千里            ← 「焼肉千里」（スペースなし）と混在させない
住所：〒154-0011 東京都世田谷区上馬4-41-2
      ← 「４−４１−２」（全角）と混在させない。半角ハイフンで統一
電話：03-3418-7496        ← 「0334187496」「(03)3418-7496」と混在させない
```
