## 1. CV改善（新規来店予約の最大化）

### 現状の実装（コードから確認）

| 導線                         | 実装                                   | 評価    |
| ---------------------------- | -------------------------------------- | ------- |
| ヘッダーCTA                  | 「電話で予約する」（md以上で常時表示） | ✅      |
| FV CTA                       | お品書き／電話予約／アクセス の3つ     | ✅      |
| モバイル固定バー             | 電話予約／地図／お品書き               | ✅ 優秀 |
| 予約CTAセクション            | 電話番号を大きく表示＋3ボタン          | ✅      |
| フッター                     | 電話・営業時間・地図                   | ✅      |
| `tel:` リンク                | `phoneHref` で一元管理                 | ✅      |
| `formatDetection: telephone` | 有効                                   | ✅      |

**CV導線は既に良好です。** 以下は上積みの提案です。

### ■問題点1：予約の心理的ハードルが高い

電話予約のみで、「何を伝えればいいか」が書かれていません。
電話が苦手な層（20〜30代）が離脱します。

**■改善内容**：予約CTAの近くに、伝える内容を明示する。

```tsx
// ReservationCTA.tsx の電話番号の下に追加
<Reveal delay={280}>
  <p className="text-gray mx-auto mt-5 max-w-md text-[0.78rem] leading-[2]">
    お電話では「ご希望の日時」「人数」「お名前」をお伝えください。
    <br className="hidden sm:block" />
    お席のご相談も承ります。
  </p>
</Reveal>
```

**■期待効果**：電話への心理的障壁の低減。実店舗でのCV率改善に直結。

### ■問題点2：営業時間外の受け皿がない

L.O.が21:30〜21:45、定休日は木曜。**閉店後・定休日に訪れた人が予約できません。**

**■改善内容**：営業時間外は「営業時間内にお電話ください」＋Instagram DMへ誘導する表示を出す。
※ 静的サイトのため、クライアント側で現在時刻を判定して表示（`useEffect` でマウント後に判定し、
Hydration差分を出さないこと）。

### ■問題点3：Instagram / LINE の活用余地

- Instagram は `sameAs` に登録済み・ヘッダーにアイコンあり ✅
- **LINE公式アカウントは未整備**。飲食店の再来店施策として費用対効果が高い

**■改善内容**：LINE公式アカウントを開設し、`site.ts` の `socialLinks` に追加。
テイクアウト予約の受付窓口にすると、電話の取りこぼしを回収できます。

### ■問題点4：口コミへの導線がない

サイトからGoogleマップの口コミへ誘導していません。

**■改善内容**：フッターかアクセスページに「Googleマップで口コミを見る」リンクを追加。
`googleMapsUrl` は既に `site.ts` にあるため、リンクを1本足すだけです。

### ■問題点5：価格の不透明さ

`store.priceRange` が空で、予算感がどこにも書かれていません。
**飲食店選びで最大の離脱要因は「いくらかかるか分からない」ことです。**

**■改善内容**：予算帯を確認し、`store.priceRange` に設定。
あわせて `/menu` の冒頭に「お一人あたり◯◯円が目安です」を明記。

## 4. やってはいけないこと（明示）

| 禁止                                       | 理由                               |
| ------------------------------------------ | ---------------------------------- |
| 口コミの自作自演・購入                     | Googleポリシー違反。アカウント停止 |
| 特典と引き換えの口コミ依頼                 | 同上                               |
| AggregateRating / Review の捏造            | 手動対策・優良誤認                 |
| 実態のない「個室あり」「コースあり」の記載 | 期待ズレ→低評価→順位下落の悪循環   |
| 中身の薄い地域ページの量産                 | ドアウェイページとして評価         |
| 実績のない受賞歴・メディア掲載の記載       | 信頼性の毀損                       |
| KWの詰め込み（タイトル・本文）             | スパム判定                         |
| 他店の口コミ・写真の転用                   | 著作権・不正競争防止法             |
