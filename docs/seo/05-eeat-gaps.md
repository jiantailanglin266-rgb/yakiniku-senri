# E-E-A-T 不足情報 確認シート｜焼肉 千里

このシートを**そのまま店舗へお渡しして埋めてもらう**ことを想定しています。
埋まった項目から順に、サイト・構造化データ・Googleビジネスプロフィールへ反映します。

> **なぜ重要か**：GoogleはYMYL以外の飲食店でも、Experience（実体験）・Expertise（専門性）・
> Authoritativeness（権威性）・Trust（信頼性）を評価します。
> AI検索はさらに顕著で、**具体的な事実が書かれているサイトほど引用されます。**
> 「美味しい」「こだわり」といった形容詞ではなく、**数値・固有名詞・年号**が効きます。

## 記入例（この粒度で書いてください）

**悪い例**：「厳選した上質なお肉を使用しています」
→ 形容詞のみ。AIも検索エンジンも引用できません。

**良い例**：「肉は東京食肉市場から週3回、仲卸の◯◯商店を通じて仕入れています。
ハラミは仕入れた当日にカットし、翌日までに使い切ります。」
→ **頻度・取引先・処理方法**という事実。引用されます。
