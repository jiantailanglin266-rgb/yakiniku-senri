# 多言語対応（自動翻訳）｜焼肉 千里

## 実装したもの

ヘッダーの地球儀アイコンから **42言語**へ切り替えられる自動翻訳を追加しました。

| 項目             | 内容                                                                     |
| ---------------- | ------------------------------------------------------------------------ |
| 対応言語         | 42（日本語＋41言語）                                                     |
| 翻訳エンジン     | Google 翻訳ウィジェット（`translate.google.com/translate_a/element.js`） |
| 費用             | 無料                                                                     |
| 切り替えUI       | `src/components/i18n/LanguageSwitcher.tsx`（国旗つき）                   |
| 国旗             | `public/images/flags/<国コード>.webp`（42点・合計16KB）                  |
| エンジン読み込み | `src/components/i18n/GoogleTranslate.tsx`                                |
| 言語一覧         | `src/data/languages.ts`                                                  |
| 状態管理         | `src/lib/translate.ts`（`googtrans` Cookie）                             |

### 対応言語

日本語／English／简体中文／繁體中文／한국어／ไทย／Tiếng Việt／Bahasa Indonesia／
Bahasa Melayu／Filipino／हिन्दी／বাংলা／தமிழ்／नेपाली／မြန်မာဘာသာ／ខ្មែរ／Монгол／
Español／Português／Français／Deutsch／Italiano／Nederlands／Русский／Українська／
Polski／Čeština／Slovenčina／Magyar／Română／Български／Hrvatski／Ελληνικά／Türkçe／
Svenska／Dansk／Norsk／Suomi／العربية／עברית／فارسی／اردو

並び順は訪日客の多い言語を上にしています（アルファベット順にしていません）。

### 国旗について

各言語に国旗を表示しています。素材は flag-icons（MIT）の SVG を、表示サイズ（約24×18px）に
合わせて 48×36 の WebP へ変換したものです（**SVG合計180KB → WebP合計16KB**）。

⚠️ **言語と国は1対1ではありません。** 英語は英国・米国など、スペイン語はスペイン・中南米など
複数の国で話されます。旗だけでは誤解を招くため、**必ずその言語での言語名を併記**しています。
プルダウン下部にも「国旗は言語の目印で、国を限定するものではありません」と明記しました。

主な対応：英語→英国／スペイン語→スペイン／ポルトガル語→ポルトガル／
アラビア語→サウジアラビア／タミル語→スリランカ。
変更する場合は `src/data/languages.ts` の `country` を書き換え、
対応する国旗を `public/images/flags/` へ追加してください。

## 設計上の判断

### 1. 日本語の訪問者には外部スクリプトを一切読み込まない

**■問題**：翻訳ウィジェットを常時読み込むと、来訪者の大半を占める日本語話者**全員**の
表示速度が落ちます。

**■対応**：`googtrans` Cookie が無い（＝日本語のまま）ときはスクリプトを読み込みません。

**■検証結果**

```
日本語時に翻訳スクリプトを読み込むか: false  ← 正しい
英語時に翻訳スクリプトを読み込むか:   true   ← 正しい
```

### 2. Cookie を書いてリロードする方式

ウィジェット内部のセレクトを直接操作すると、翻訳がハイドレーション中に走って
表示が壊れることがあります。Cookie を書いてから読み込み直すことで、
ウィジェットが初期化時にまとめて翻訳するため崩れにくくなります。

### 3. 店名・住所・電話番号は翻訳しない

**■問題**：機械翻訳は住所や電話番号を勝手に書き換えることがあります。
**来店・予約に直結する情報が壊れると被害が大きい**ためです。

**■対応**：`translate="no"` を付与。

- 電話番号（ヘッダー／フッター／CTA／アクセス／お問い合わせ／モバイルナビ）
- 住所（フッター／アクセス）
- 言語切り替えUI自体（言語名が翻訳されると意味を失うため）

### 4. 失敗しても本文は読める

スクリプトが読み込めない場合（ネットワーク遮断・地域制限・Googleの仕様変更など）、
日本語のまま表示し、小さな通知と「日本語表示に戻す」ボタンだけを出します。

**■検証結果**（`translate.google.com` を遮断して確認）

```
失敗時の通知: 翻訳サービスに接続できませんでした。日本語のまま表示しています。
本文（h1）:   炎とともに、受け継がれる味。      ← 読める
戻したあとのCookie: なし                        ← 正しく削除
```

### 5. 右横書き（RTL）対応

アラビア語・ヘブライ語・ペルシャ語・ウルドゥー語を選ぶと
`<html dir="rtl">` に切り替えます。

### 6. ウィジェットのレイアウト崩れを抑止

Google 翻訳は画面上部に自前のバーを挿入し、`body` に `top` を付けてページを押し下げます。
固定ヘッダーと衝突するため、CSS でバーを隠し押し下げを打ち消しています（`globals.css`）。

## ⚠️ SEOに関する重要な注意

### 自動翻訳ページは検索評価の対象になりません

この実装は**クライアント側の翻訳**です。次の性質があります。

| 項目                       | 状態                                |
| -------------------------- | ----------------------------------- |
| 翻訳版のURL                | **生成されません**（同一URLのまま） |
| 検索エンジンのインデックス | **されません**（日本語版のみ）      |
| hreflang                   | 対象URLが無いため**設定不要**       |
| AI検索での引用             | 日本語版が対象                      |

**つまり「英語で検索して見つけてもらう」効果はありません。**
すでにサイトへ来た外国人訪問者が読めるようにする、**接客のための機能**です。

### 40言語を機械翻訳して静的に生成してはいけません

「40言語ぶんのページを生成してインデックスさせる」ことは**推奨しません**。

Googleのスパムポリシーは「**人間による確認を経ていない機械翻訳のテキスト**」を
**スケーリングされたコンテンツの不正使用**として明確に禁止しています。
世田谷の一店舗が40言語の低品質ページを大量生成すると、
サイト全体の評価を落とすおそれがあり、`docs/seo/` の他の施策を台無しにします。

### 検索流入も狙う場合の正しい進め方

**言語を絞り、人の手で確認した翻訳を静的に持つ**のが唯一の正解です。

```
推奨：英語・簡体中文・繁體中文・韓国語 の4言語

理由：駒澤大学駅周辺／世田谷の訪日客構成と、
      翻訳品質を人が確認できる現実的な上限

実装：next-intl などで /en /zh-cn /zh-tw /ko のルーティングを作り、
      src/data/ 配下のテキストを言語別に持つ
      → hreflang を設定 → 各言語版がインデックスされる

工数：初期翻訳＋確認で1言語あたり2〜3日程度
      （store.ts / menu.ts / content.ts / 各ページのメタデータ）
```

**現在の自動翻訳（42言語）と、この4言語の静的翻訳は共存できます。**
静的翻訳がある言語はそちらを見せ、それ以外は自動翻訳で受ける、という構成が理想です。

| 言語名がその言語の自称で表示される       | ✅                      |
| 英語選択で `googtrans=/ja/en` が書かれる | ✅                      |
| 選択後にスクリプトが読み込まれる         | ✅                      |

### 未確認事項

**実際の翻訳表示は確認できていません。** この環境は `translate.google.com` へ到達できないためです。
公開後に、実際に言語を切り替えて以下をご確認ください。

1. 各言語で本文が翻訳されるか
2. 電話番号・住所が**翻訳されずに残っている**か（最重要）
3. ヘッダーがずれていないか
4. モバイルで表示が崩れていないか
5. RTL言語（アラビア語など）で右横書きになるか

なお、Google 翻訳ウィジェットはGoogleの提供終了・仕様変更の影響を受ける可能性があります。
その場合も**本文は日本語のまま読める**設計にしてあるため、サイトが壊れることはありません。
