# チャットボット｜焼肉 千里

## 方式：FAQ応答型（AI非搭載）

| 項目             | 内容                                   |
| ---------------- | -------------------------------------- |
| 応答方式         | 登録済みの意図とキーワードの照合       |
| AI（LLM）        | **使用しない**                         |
| 外部通信         | **なし**（すべてクライアント内で完結） |
| 費用             | **0円**（APIキー・サーバー不要）       |
| 静的ホスティング | **そのまま動作**（GitHub Pages 可）    |
| 応答データ       | `src/data/chatbot.ts`                  |
| 照合ロジック     | `src/lib/chat-match.ts`（テストあり）  |
| UI               | `src/components/chat/ChatBot.tsx`      |

### なぜAIを使わないのか

営業時間・価格・定休日を**誤って答えると来店後のトラブルに直結**します。
大規模言語モデルは、もっともらしい誤情報を自信を持って答えることがあり、
飲食店の一次情報を扱う用途には向きません。

さらに本サイトは42言語へ自動翻訳されるため、**誤答はそのまま多言語で拡散**します。
`AGENTS.md` に定めた事実性の要件（未確認情報を載せない）とも衝突します。

そのため、**確認済みの事実を、決まった文面で返す**方式にしています。

## 登録している意図（18）

### 回答できるもの（13）

| 意図         | 質問の例                 | 回答の根拠                          |
| ------------ | ------------------------ | ----------------------------------- |
| 営業時間     | 何時まで営業していますか | `store.businessHours`               |
| 定休日       | 定休日はいつ             | `store.closed`                      |
| 予約         | 予約したい               | `store.phone`                       |
| 場所・行き方 | どこにありますか         | `store.address` / `store.access`    |
| 駐車場       | 駐車場はありますか       | `store.parking`                     |
| おすすめ     | おすすめは何ですか       | `menu.recommendedItems`（価格つき） |
| もみシリーズ | もみって何               | `content` / `menu`                  |
| 価格の税表記 | 税込ですか               | `store.priceTaxIncluded`            |
| 予算         | いくらくらい             | 未設定のため電話案内                |
| テイクアウト | 持ち帰りできますか       | `content.takeout`                   |
| 電話番号     | 電話番号は               | `store.phone`                       |
| 創業・歴史   | いつからのお店           | `store.founded`                     |
| オーナー     | 店主はどんな人           | `content.owner`                     |

**回答はすべてデータから組み立てています。**`store.ts` の営業時間を変えれば、
チャットボットの回答も自動で変わります。二重管理になりません。

### 意図は拾うが、情報がないもの（5）

個室・席／支払い方法／子連れ・ペット／アレルギー／コース・飲み放題・ランチ

これらは**黙って無視せず**、「ご案内できる情報がございません。お電話にてご確認ください」
と正直に答え、電話リンクを添えます。

> `docs/seo/05-eeat-gaps.md` の確認が済んだら、この5つを実際の回答に差し替えてください。
> それだけでチャットボットの実用性が大きく上がります。

## 照合の仕組み

形態素解析なしで日本語を扱うため、**登録キーワードの部分一致**で判定しています。

```
1. 入力を正規化（NFKC → 小文字化 → 空白・句読点を除去）
   「ＴＡＫＥ　ＯＵＴ！」→「takeout」

2. 各意図のキーワードが含まれるか調べ、
   一致したキーワードの文字数を加算

3. 最高スコアの意図を採用（2点未満は「聞き取れませんでした」）
```

長いキーワードほど高く評価します（「予約」より「予約したい」のほうが具体的なため）。

### 実測

```
「営業時間は何時までですか」  → hours    ✅
「駐車場ありますか」          → parking  ✅
「個室はありますか」          → seats    ✅（情報がない旨を回答）
「今日の天気」                → 該当なし ✅（候補ボタンへ誘導）
「What are your opening hours?」→ hours  ✅
「Is parking available?」      → parking ✅
```

主要な意図には英語のキーワードも登録済みです。

## アクセシビリティ

| 項目           | 対応                                                        |
| -------------- | ----------------------------------------------------------- |
| キーボード操作 | すべて可能。Escape で閉じ、**フォーカスが起動ボタンへ戻る** |
| 読み上げ       | `role="log"` / `aria-live="polite"` で新しい発言を通知      |
| ラベル         | 起動ボタン・閉じるボタン・入力欄すべてに設定                |
| タップ領域     | 44px以上                                                    |
| 印刷           | `no-print` で非表示                                         |

## レイアウト

| 環境         | 配置                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------ |
| デスクトップ | 右下（`bottom-6 right-6`）                                                                       |
| モバイル     | 固定バーの上（`bottom-20`）。**重なりがないことを実測で確認**（ボタン下端764px / バー上端779px） |
| z-index      | 起動ボタン86・パネル94。ヘッダー90・モバイルナビ95とぶつかりません                               |

## 多言語との関係

表示文はDOM上のテキストなので、**自動翻訳の対象になります**（42言語）。

⚠️ ただし**利用者の入力は翻訳されません**。日本語・英語以外で入力された場合は
候補ボタンで拾う設計です。候補ボタンのラベルも翻訳されるため、
外国語の利用者はボタンから選べます。

本文中の電話番号は `translate="no"` で翻訳対象から外しています。

## 回答の追加・修正

`src/data/chatbot.ts` の `chatIntents` に追記するだけです。

```ts
{
  id: "example",
  label: "候補ボタンに出す短い質問",
  suggested: true,              // 最初から候補ボタンに出すか
  keywords: ["表記ゆれ", "を", "並べる", "english too"],
  answer: "確認済みの事実だけを書く",
  links: [{ label: "お品書きを見る", href: "/menu" }],
}
```

**`answer` には必ずサイトに掲載済みの事実だけを書いてください。**
推測で書くと42言語へ翻訳されてそのまま拡散します。

キーワードを追加したら `tests/chat-match.test.ts` にも1行足しておくと、
将来の変更で壊れたときに気づけます。
