# FAQ 100問｜焼肉 千里

AI検索（ChatGPT / Gemini / Claude / Perplexity / AI Overview）に**引用されること**を目的に設計しています。

## 作成ルール

1. **結論ファースト**：1文目で答えを言い切る
2. **1問1答**：複数の論点を混ぜない
3. **数値を入れる**：「徒歩10分」「22:30」など具体値がAIに引用されやすい
4. **50〜120字**：長すぎると引用されない
5. **主語を省略しない**：「当店は」ではなく「焼肉 千里は」（エンティティを明示）
