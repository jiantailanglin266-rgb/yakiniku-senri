### 生成AIに引用されやすい構造

ニュース記事の本文は **結論 → 要点 → データ → 背景 → 注意点** の順に固定しています。
最初の段落だけで結論が伝わるため、引用時に文脈が失われません。

配信比較・Web3.0 詳細・ベッティング情報も同じ方針で、
「結論」「確認すべき点」「リスク」を見出し単位で分離しています。

### 権利の扱い

| 項目               | 対応                                                                |
| ------------------ | ------------------------------------------------------------------- |
| 試合映像           | 配信・転載しない。権利者公開動画の埋め込みのみ                      |
| チーム／リーグロゴ | **使用しない。** チームカラーとイニシャルから自前でモノグラムを生成 |
| 選手写真           | **使用しない。** 背番号とチームカラーで識別                         |
| 試合データ         | 提供元の規約に従う。再配布禁止の場合は第三者提供しない              |
| 違法配信サイト     | リンクしない（掲載方針に明記）                                      |

### 広告表記

- 広告リンク：`rel="sponsored nofollow"` + 「PR」バッジ + `data-affiliate` 属性
- 掲載順位が報酬額で決まらないことをフッターと各方針ページに明記
- テスト（`tests/sports-components.test.tsx`）が rel と表記の欠落を検出

### ベッティング関連

**事業者名・リンク・アフィリエイトリンクを一切掲載していません。**

理由（`/betting` と `/legal/betting-policy` に明記）：

1. 日本国内から海外のベッティングサービスを利用する行為は法令に抵触するおそれがあり、当サイトの主要読者は国内在住者
2. 免許番号・対応地域・出金条件を自社で検証できない事業者は載せないという方針

代わりに以下を掲載しています。

- 年齢制限（18歳以上、地域により21歳以上）の明示
- 地域制限の明示
- 責任ある利用（入金上限・利用時間管理・自己排除制度・依存リスク）
- 「もし検討するなら何を確認すべきか」の8項目
- 公的相談窓口への案内

以下は**サイト全体で使用しません**（診断・AI分析・チャットボットを含む）。

- 試合結果の予言 / 利益・勝率の保証 / 「必ず勝てる」等の表現
- 損失回復や賭け金増額を促す表現
- 年齢制限・地域制限の回避（VPN利用を含む）の案内
- 借入による利用を促す表現

チャットボットが勝敗を尋ねられたときに予言しないことを、テストで検証しています。
