# E2E テスト（Phase 2）

Phase 1 では未実装です。実装時に以下のシナリオを対象とします（仕様書 §20）。

- 顧客が公開ページから予約する
- スタッフが予約台帳で予約を確認する
- 来店処理 → 施術開始 → 施術完了
- カルテ入力
- 会計（Phase 2 の機能実装後）
- 次回予約
- キャンセル待ちの繰り上げ（Phase 3）
- 店舗追加
- スタッフの権限変更が画面に反映される

現時点で最も価値の高い E2E は「公開予約 → 台帳表示 → 来店処理 → カルテ入力」の
一連の流れです。これは Phase 1 の完成条件をそのままなぞります。

ブラウザ自動化には Playwright を想定しています。
