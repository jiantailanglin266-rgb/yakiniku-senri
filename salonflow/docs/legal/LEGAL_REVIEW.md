# 法務確認項目

**本書は法的助言ではありません。** 開発チームが実装上認識している論点を整理し、
弁護士・税理士・社労士・弁理士による確認が必要な事項を列挙したものです。
法的結論は一切記載していません。すべて「確認が必要な項目」として扱ってください。

- 最終更新: 2026-08-03
- 対象: SalonFlow Phase 1

## 0. 大前提：知的財産と競合サービスの取り扱い

本プロダクトは、**公開情報と一般的なサロン業務要件のみ**を基に独自設計しました。

### 実施していないこと（記録）

- 特定既存サービスの名称・ロゴ・商標の使用
- 既存サービスの画面デザイン・配色・文言・アイコン・HTML の複製
- 既存サービスの非公開 API・内部仕様・データ構造の参照
- 既存サービスへの不正アクセス、スクレイピング、リバースエンジニアリング
- 実在しない連携実績・導入実績・認定表示の掲示

### 実装済みの技術的対応

- 同意の取得・撤回を `CustomerConsent` に記録（取得時 IP / User-Agent 付き）
- カルテ閲覧・写真表示・CSV 出力を監査ログへ記録
- 顧客連絡先・カルテ写真のロール別マスキング（サーバー側で値を落とす）
- カルテ写真は署名付き短期 URL でのみ配信（推測不可能）
- 削除依頼に対する匿名化処理（識別情報を上書き、会計行は保持）
- 監査ログからのパスワード・トークン・カード番号の自動除去

## 9. 外部 API 利用規約

現時点で外部サービスへの接続は一切行っていません。
接続する場合は、以下を各サービスの正式な利用規約に基づいて確認してください。

| # | 対象 | 確認事項 |
| --- | --- | --- |
| API-1 | 決済事業者 | 加盟店審査、PCI DSS 上の責任分界、カード情報非保持の構成 |
| API-2 | メール送信事業者 | 送信レート、送信ドメイン認証（SPF / DKIM / DMARC）、バウンス処理義務 |
| API-3 | SMS 事業者 | 送信可能時間帯、本人確認、国際送信 |
| API-4 | LINE Messaging API | 公式アカウント開設、利用規約、メッセージ通数上限 |
| API-5 | 地図サービス | 表示要件、キャッシュ禁止条項、課金 |
| API-6 | 外部予約サービス | **正式な API 契約がない限り接続しない。** 自動操作・スクレイピングは行わない |

> **重要**: 外部予約サービスとの連携は、
> 正式な API 契約・OAuth・Webhook・利用者自身が正当に取得した CSV の
> インポートのみを手段として認めます。
> 利用規約に反する自動操作やデータ取得は行いません。
